# 소방공무원 승진 점수 계산기

소방공무원 **승진대상자명부 점수**(근무성적·경력·교육훈련·전문능력·체력검정·가점)를 계산하는 웹 앱입니다. 계급을 선택하면 계급별 배점·평정횟수가 자동 반영되고, 원점수와 명부 환산점수를 함께 보여주며, 부족한 항목을 채우는 자격증을 추천합니다.

## 근거 법령·규정 (현행)

- 소방공무원 승진임용 규정 (대통령령 제35641호, 시행 2025. 7. 8.) — 제9조·제10조·제11조
- 소방공무원 승진임용 규정 시행규칙 — 제7조·제13조·제19조 및 **별표3**(개정 2024. 1. 11.)
- 소방공무원 교육훈련성적 평정규정 (소방청예규 제117호, 시행 2026. 1. 1.) — 제11조·제12조

## 점수 구조

명부 100점 = 근무성적(70%) + 경력(15%, 소방정 20%) + 교육훈련(15%, 소방정 10%), 여기에 가점 5점 이내 별도.

| 항목 | 원점수 만점 | 명부 환산 |
|---|---|---|
| 근무성적평정 | 60 | 70 |
| 경력평정 | 25 (소방정 30) | 15 (소방정 20) |
| 교육훈련성적 | 15 (소방정 10) | 15 (소방정 10) |
| 가점 | — | 5점 이내(별도) |

교육훈련성적 구성(영 제10조②): 소방장 이하 = 전문교육훈련3 + 직장훈련4 + 체력검정5 + 전문능력3 / 소방위·경·령 = 관리역량3 + 전문교육훈련3 + 직장훈련4 + 체력검정5 / 소방정 = 소방정책관리자교육10.

## 파일 구성

- `index.html` — 페이지 구조
- `styles.css` — 반응형 스타일(모바일·PC)
- `data.js` — 별표3·예규 등 **기준 데이터(근거 원문)**
- `engine.js` — 순수 계산 로직 (Node에서 단위테스트 가능)
- `app.js` — UI 렌더링·실시간 계산·추천·Supabase 익명 로깅
- `config.js` — Supabase 접속 설정(비어 있으면 저장 비활성, 계산은 정상)

## 로컬 실행

정적 파일이라 서버가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다. (또는 `npx serve`)

## 참고

참고용 계산기입니다. 근무성적평정점 등 미확정 항목은 예상치이며, 가점의 세부 배점(자격증·어학)은 「소방공무원 가점평정 규정」에 따르므로 항목별 상한만 반영합니다. 실제 명부 점수와 다를 수 있습니다.
